# Contributing

Keep contributions within the synthetic work packages and evidence-policy scope of this repository. Do not add employer data, customer material, credentials, raw model output, or private deployment files.

Run the locked dependency test suite before opening a Pull Request. Changes to evaluation fixtures must update the frozen manifests intentionally and include the resulting validation evidence.

Use a feature branch and Pull Request. Explain skipped live-model checks; normal CI must remain offline and deterministic.
